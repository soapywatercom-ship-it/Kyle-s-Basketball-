# KYLE'S BASKETBALL

Foundation implementation for a mobile-first 3D basketball simulation architecture.

## Phase 1 status

Phase 1 (Foundation) is implemented in `cpp/` with a compile-ready C++ baseline and detailed architecture notes in:

- `docs/PHASE_01_FOUNDATION.md`

## Build

```bash
cd cpp
cmake -S . -B build
cmake --build build
./build/kb_foundation
```

## Branding

Use `Kyle's Basketball logo.png` as the official visual identity for app icon, splash, title, and main menu styling.
